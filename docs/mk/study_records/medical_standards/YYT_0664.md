# 赋予软件安全级别

```mermaid
flowchart TB

    START(["C级（默认）"])

    Q1{"软件失效能否<br/>引起危险情况？"}

    EXT["评价外部风险控制<br/>措施的有效性"]

    Q2{"软件失效是否导致不可<br/>接受的风险？"}

    Q3{"可能造成何种严重程度的<br/>损伤？"}

    A(["A级"])
    B(["B级"])
    C(["C级"])

    START --> Q1

    Q1 -- "否" --> A
    Q1 -- "是" --> EXT

    EXT --> Q2

    Q2 -- "否" --> A
    Q2 -- "是" --> Q3

    Q3 -- "非严重损伤" --> B
    Q3 -- "严重损伤/死亡" --> C
```
